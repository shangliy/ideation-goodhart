## 解读
- 两个预注册判定都是 inconclusive。
- **只给 probe 列表（D0）就拿到了大部分提升**：
  - SV 比 BASE 多 0.75（p = .003），干净测量多 1.04，粗略看约 70% 的提升不需要任何测量值；
  - D0 的精度（.79）反而高于所有带数值的臂。
- **错误数值有害**：
  - 打乱数值（S）后，SV 降到 1.42，与 BASE 没有显著差别；
  - 精度为 .58，是所有臂中最低。
- **精度排序**：无数值 .79 > 正确数值 .75 > 加噪 .71/.69 > 代理 .65 > 打乱 .58。
  - 在这个空间里，数值对精度整体是负贡献；数值越准，伤害越小。
  - 正确数值相对 D0 的 SV 增益（+0.29）不显著。
- **对论文第 3 条的含义**：
  - 原来的说法是"真实测量推动了前沿"，这个说法站不住，至少大部分效应不来自测量内容。
  - 更接近数据的说法是：**先让模型设计具体实验（逐个写出父 cell 和编辑），再提假设，本身就推动了前沿**。这是一种不引入外部信息的 harness 改动。
  - 这与 D（"只改内部推理推不动前沿"）冲突：D 测过的那 18 个 harness 里没有"先设计实验"这一种。
  - 测量值起的作用更像一把双刃剑：正确时小幅增加 SV、略降精度；错误时两者都伤。
- **注意**：
  - D0 vs BASE 不是本阶段的预注册主比较；不过 p = .003，做任何小规模的多重校正后都还显著；
  - 设计调用是在"会拿到结果"的预期下做的，D0 的 probe 列表在这一点上与真正"无测量"的设计流程不同；
  - 只有 Opus、一个空间。
