## 读法
- **A 的稳健部分**是"judge 分升、精度崩、先验大降"，两个模型都成立。
- **"judge 优化让 SV 下降"不稳健**：阶段 2 中 Sonnet 是 1.62 → 0.62，这里没有重复出来。
  - judge 臂少了很多真主张，但剩下的真主张大多是低先验的，所以 SV 大致不变。
  - 它在前沿上移动到"低精度、低先验"的一端，并没有推动前沿。
- **测量对 Opus 有效，对 Sonnet 无效。**
  - Opus 主动测量臂在三批独立运行中都是 2.12（8、8、24 次），直接生成三批分别是 1.00、2.00、1.08。
  - Sonnet 拿到测量后精度崩塌，SV 不变。
  - 这与 P1 一致：面对纯噪声级的测量，Sonnet 在"根据测量重新考虑"的追问下 94% 改为跟随，Opus 只有 41%。
- **成本**：主动测量臂约 33k token/次，直接生成约 6k。按 SV/1k token 算，直接生成仍然更高；但测量臂的绝对 SV 翻倍。
- **局限**：
  - 测量来自表格化的多种子均值，噪声低于真实实验；
  - A-100 是看过阶段 4 数据后选中的臂，但本阶段用的是事先固定的全新运行；
  - 只有一个空间。
