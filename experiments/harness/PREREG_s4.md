# 阶段 4 预注册：测量旋钮能不能推动精度–意外度前沿（2026-10-20，写于任何阶段 4 调用之前）

## 问题
阶段 1 到 3 表明：只改内部推理的 harness 干预（检索、角色、挑战、选择、strategy 文本）推不动 SV。这里的 SV 指为真、且留一先验 < 50 的主张。

前期 P1 表明：只有外部测量能带来有精度的判断修正。

本阶段要回答的是：**允许 harness 在提出假设之前做少量真实测量，SV 会不会超过直接生成？**

## 测量的定义（NB201）
- **一次测量** = 一个（父 cell，编辑）对，返回这个编辑在 3 个数据集上的准确率变化（百分点，保留 2 位小数）。
  - 编辑的写法是"把边 j 设为算子 b"。
  - 准确率用 **test** 划分；判真用的是 **val** 划分。两者来自同一批训练，但评测数据不同，这样测量值和真值不是同一组数字。
  - 表里的准确率是多个种子平均后的值，所以单次测量的噪声比真实实验小，作为局限报告。
- **随机测量 R-k**：每次运行独立随机抽 k 个（父 cell，编辑）对。父 cell 在 15,625 个 cell 里均匀抽；编辑在该父 cell 合法的 24 个编辑里均匀抽。随机种子 = rep。
- **主动测量 A-k**：分两步。
  1. 生成模型先设计 k 个测量，每个指定父 cell 的 6 个算子和一个编辑；
  2. Python 返回结果，生成模型再提出 10 条假设。
  - 不合法的测量直接跳过，并记录个数。

## 实验臂（NB201，每格全新运行 8 次，rep 100–107）
| 臂 | 说明 |
|---|---|
| k = 0 | 直接生成。复用阶段 2 和 3 已有的新运行（Sonnet：final.json 的 nb\|BASE；Opus：frontier_opus.json 的 BASE） |
| R-20、R-100、R-400 | 随机测量 |
| A-20、A-100 | 主动测量 |

- 生成模型：Sonnet 和 Opus。
- 留一先验 = 排除生成模型以后，其余两个模型的均值。
- 提出假设时的 prompt 与直接生成相同，只是在前面插入测量结果，并说明"这些是真实测量，可作为证据"。
- 输出契约不变。

## 指标
每次运行的 SV、精度、平均留一先验、token、主动测量中的不合法个数。

## 判据
- **M1 测量推动前沿**
  - 支持：至少一个生成模型上，某个测量臂的 SV 显著高于 k = 0（单侧置换检验，每个模型 5 个比较做 Holm 校正，p < .05），且该臂精度 ≥ 0.8 × k = 0 的精度。
  - 否定：两个模型上，所有测量臂的 SV 都 ≤ k = 0 + 0.3。
  - 其余：inconclusive。
- **M2 剂量反应**（随机臂）
  - 对每个生成模型，用 k ∈ {0, 20, 100, 400} 的全部运行计算 Spearman(k, SV)。
  - 支持：两个模型都是 ρ > 0 且 p < .05。
  - 否定：两个模型都是 ρ ≤ 0。
  - 其余：inconclusive。
- **M3 主动 vs 随机**（描述性）：同为 k = 20、k = 100 时，主动和随机在 SV 和精度上的差（单侧置换检验的 p）。

## 替代解释和对照
- **测量其实是在泄露真值**：
  - 测量用 test 划分，判真用 val 划分；
  - 判真依据的是每个格子上数百到数千个父 cell 的平均差，单次测量最多只覆盖其中的一个点；
  - 另外报告"提出的主张所在格子，是否被测量直接覆盖过"的比例，这是描述性指标。
- **只是多给了 token**：k = 400 的 prompt 最长，同时报告 token 和 SV/1k token。
- **随机波动**：阶段 2 和 3 中，两批直接生成之间就差了 0.37 条/次。判据用 Holm 校正，并要求精度约束。
