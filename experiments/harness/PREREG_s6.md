# 阶段 6 预注册：带噪声的测量（2026-10-21，写于任何阶段 6 调用之前）

## 问题
阶段 5 中，Opus 自己设计 100 次实验（A-100）后，SV 从 1.08 翻倍到 2.12。但那些测量是多种子平均后的查表值，比真实的单次实验干净。
本阶段要回答：**测量带有现实噪声，或者只是低保真代理时，这个提升还在不在？**

## 设计
- 生成模型：只用 Opus（M 只在 Opus 上成立）。
- rep 116–139，共 24 次。**复用阶段 5 中 Opus A-100 已经设计好的实验**（`mA100_nb_r{rep}_opus_design.json`），只把返回给模型的测量值换掉，再重新调用一次"读结果、提假设"。
- 这样每个噪声臂与干净 A-100 用的是完全相同的实验设计，可以做配对比较。
- prompt 与 A-100 完全相同（仍说"这些是真实测量"），不告诉模型有噪声。这对应真实场景：自主研究 agent 拿到的单次运行结果不带噪声说明。

## 实验臂
| 臂 | 返回给模型的测量值 |
|---|---|
| N1 现实噪声 | 干净差值 + 高斯噪声，3 个数据集的标准差分别为 √2 × (0.3, 0.6, 0.9) = (0.42, 0.85, 1.27) 个百分点 |
| N2 双倍噪声 | 标准差为 N1 的 2 倍：(0.85, 1.70, 2.55) |
| L 低保真代理 | 用 NB201 表里 12 个 epoch 训练的准确率差值（`e12` 字段），不用完整训练的 test 差值 |

- 噪声随机种子 = rep；数值保留 2 位小数。
- N1 的单种子标准差 (0.3, 0.6, 0.9) 是**假设**，按 NB201 原论文中跨种子标准差的大致量级取值，没有逐种子数据可直接核对。作为局限报告；N2 用来覆盖"噪声被低估"的情形。
- 参照量（这些 probe 上干净差值的中位绝对值）：C10 0.70，C100 1.74，IN16 2.77。所以 N1 的噪声约为典型效应的一半，N2 约与典型效应相当。
- L 是真实数据，不是合成噪声。在这些 probe 上，它与完整训练差值的相关系数为 0.67 / 0.49 / 0.77，符号一致率约 0.70。

## 对照
- BASE：阶段 5 中 Opus 直接生成，同样的 rep 116–139（n = 24），SV 1.08，精度 .87。
- 干净 A-100：阶段 5 中 Opus 的 A-100，同样的 rep 和 probe（n = 24），SV 2.12，精度 .75。

## 判据
- **主判据：对每个臂 X ∈ {N1, N2, L}，判定"M 在 X 下是否成立"**
  - 比较 X 与 BASE 的 SV，用单侧置换检验（5000 次），3 个比较做 Holm 校正。
  - 支持：Holm p < .05，且 X 的精度 ≥ 0.8 × BASE 的精度。
  - 否定：X − BASE 的 90% bootstrap CI 上界 < 0.5。
  - 其余：inconclusive。
- **次要判据（描述性）**：X 与干净 A-100 的配对差（同一 rep、同一 probe），报告 SV 和精度的均值差及 90% bootstrap CI。

## 事前预期（写下来，用于事后对照）
- N1：支持（SV 下降不到一半）。
- N2：inconclusive 或支持，精度明显下降。
- L：不确定。符号一致率只有 0.70，可能让精度明显下降。

## 替代解释
- **提升来自"看到很多实验格式"而不是测量内容**：N2 和 L 正好检验这一点。如果噪声很大时 SV 仍然一样高，说明测量内容的贡献小，M 的解释需要改写。
- **随机波动**：使用配对设计，并用同一批 BASE。

## 成本（订阅 CLI）
3 个臂 × 24 次 × 1 次调用 = 72 次 Opus 调用；不调用 judge，不新增设计调用。
