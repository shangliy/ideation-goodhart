# 阶段 5 预注册：加大样本量的确认实验（2026-10-20，写于任何阶段 5 调用之前）

## 动机
- 每臂 8 次运行时，同一个 harness 两批之间可以相差 0.37（Sonnet）到 1.0（Opus）条 SV/次，可检测的最小效应约为 1 条/次。
- 因此 D（harness 推不动前沿）和 M（测量能推动前沿）都卡在检验效力不够上。
- 本阶段用全新的、更大的样本，对最关键的 3 个臂做确认。

## 设计
- 生成模型：Sonnet 和 Opus。
- 每个生成模型 × 每个臂，跑 **24 次全新运行**（rep 116–139）。之前任何阶段都没有用过这些 rep。
- 3 个臂，都在看到本阶段数据之前固定：
  1. **BASE**：直接生成；
  2. **final_J**：阶段 2 中 judge 臂的最终 harness；
  3. **A-100**：阶段 4 的主动测量臂（模型设计 100 次实验，测量用 test 划分）。
- **Opus 的 BASE 和 final_J 的每次运行都由 judge（Opus）打分**，补齐"Opus 上 judge 分是否上升"这一点。Sonnet 的 judge 效应在阶段 2 已经测过，这里不再打分。
- 指标：每次运行的 SV、精度、平均留一先验、token；Opus 的 BASE 和 J 臂另有 judge 分。

## 统计
- **主分析只用本阶段的新运行**（每臂 n = 24），不与之前的运行合并，避免"看过数据再加样本"的偏差。
- 比较用单侧置换检验（5000 次）。每个生成模型内部，对 SV 的 2 个比较（A-100 vs BASE、final_J vs BASE）做 Holm 校正。
- 每个差值另给 90% bootstrap 置信区间（5000 次），用来说明"能排除多大的效应"。
- 次要分析：与之前全部新运行合并后的结果，只作描述。

## 判据
- **A-prec（judge 优化让精度崩塌）**
  - 支持：两个生成模型上，final_J 的精度都比 BASE 低 ≥ 0.2，且单侧 p < .05。
  - 否定：任何一个模型上，精度差 > −0.1。
  - 其余：inconclusive。
- **A-judge（Opus 上 judge 分上升）**
  - 支持：final_J 的 judge 分高于 BASE，单侧 p < .05。
  - 否定：final_J 的 judge 分 ≤ BASE。
  - 其余：inconclusive。
- **A-SV（judge 优化让 SV 下降）**：对每个生成模型分别判定。
  - 支持：final_J 的 SV 低于 BASE，单侧 p < .05。
  - 否定：final_J 的 SV ≥ BASE。
  - 其余：inconclusive。
- **M（测量推动前沿）**：对每个生成模型分别判定。
  - 支持：A-100 的 SV 高于 BASE（Holm 校正后 p < .05），且精度 ≥ 0.8 × BASE。
  - 否定：差值 90% CI 的上界 < 0.5，即排除了 ≥ 0.5 条/次的提升。
  - 其余：inconclusive，并报告 CI 上界作为"能排除的提升"。
- **D 的效力补充**：报告"BASE vs final_J"和"BASE vs A-100"两个 SV 差值的 90% CI。D 的结论写成"排除了大于 CI 上界的提升"。

## 检验效力（事前计算）
- 每次运行 SV 的标准差约 0.9。n = 24 时，差值的标准误约 0.26，单侧 α = .025、检验效力 80% 时，可检测的最小效应约为 0.73 条/次。
- 这仍然达不到 0.5。所以 M 的"否定"判据要求 CI 上界 < 0.5，有可能一个模型都达不到，结果就会是 inconclusive。
